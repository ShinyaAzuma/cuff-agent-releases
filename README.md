# Cuff Agent

Apple Watch から声で AI エージェント（Claude Code など）に仕事を任せ、終わったら結果が手首に届くアプリの、Mac 用の配布物です。

このリポジトリには配布用の DMG（[Releases](https://github.com/ShinyaAzuma/cuff-agent-releases/releases)）だけを置いています。

## 入れ方

- [Releases](https://github.com/ShinyaAzuma/cuff-agent-releases/releases/latest) から `CuffAgent-<版>.dmg` を開き、`Cuff Agent.app` をアプリケーションにドラッグ
- または Homebrew：`brew install --cask shinyaazuma/cuff/cuff-agent`

Apple シリコンの Mac、macOS 26 以上が必要です。入れたあとの更新はアプリが自動で行います。
