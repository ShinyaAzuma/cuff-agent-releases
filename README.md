# Cuff Agent

Hand off work to your AI agent (Claude Code and more) by voice from your Apple Watch, and get the result back on your wrist when it's done.

This repository hosts the macOS app downloads only — see [Releases](https://github.com/cuff-agent/cuff-agent-releases/releases).

## Install

- Download `CuffAgent-<version>.dmg` from the [latest release](https://github.com/cuff-agent/cuff-agent-releases/releases/latest), open it, and drag `Cuff Agent.app` into Applications
- Or with Homebrew: `brew install --cask cuff-agent/cuff/cuff-agent`

Requires an Apple silicon Mac running macOS 26 or later. The app keeps itself up to date.
